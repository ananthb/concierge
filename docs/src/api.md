# API Documentation (rustdoc)

The full Rust crate documentation generated by `cargo doc --no-deps` is published alongside this book:

- **[Open `replybots` rustdoc](/api/replybots/index.html)**

To build it locally:

```sh
./scripts/build-frontend.sh   # required by build.rs to hash public/app.js
cargo doc --no-deps --open
```
